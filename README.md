  ## Week 4 – Arrays, Strings & Algorithms

  This week was focused on **arrays, strings, and algorithmic problem-solving**. I practiced advanced array manipulations, implemented searching and sorting algorithms, explored string operations and pattern checks, and strengthened my understanding of stacks, queues, and matrices. These challenges improved my logical thinking, coding efficiency, and confidence in handling real-world algorithmic problems using JavaScript.

  **Exercises:**

1. **Find Second Largest Number in an Array** – Learn to track max and second max without sorting.
2. **Merge Two Sorted Arrays** – Combine arrays efficiently while maintaining order.
3. **Rotate Array K Times to the Right** – Practice array rotation logic.
4. **Intersection of Two Arrays** – Extract common elements from two arrays.
5. **Rearrange Array (Even Before Odd)** – Maintain relative order while segregating even and odd numbers.
6. **Binary Search Algorithm** – Search efficiently in a sorted array.
7. **Rock, Paper, Scissors Game** – Simulate a simple game using randomization.
8. **Menu-Based ATM System** – Build a console-based system for balance, withdraw, deposit, and exit.
9. **String Compression** – Compress strings by counting consecutive repeated characters.
10. **Check Unique Characters** – Validate if a string contains only unique characters.
11. **String Rotation Check** – Check if one string is a rotation of another.
12. **Character Frequency Counter** – Count occurrences of each character in a string.
13. **String Pattern Matching (“abba”)** – Verify if a sentence follows a specific pattern.
14. **All Permutations of a String** – Generate all possible arrangements of a string.
15. **Kadane’s Algorithm (Max Subarray Sum)** – Find maximum sum of contiguous subarray.
16. **Matrix Multiplication** – Multiply two matrices manually using loops.
17. **Sentence Abbreviation** – Create abbreviations from the first letters of words.
18. **Implement a Stack (Array-Based)** – Learn push, pop, peek, and isEmpty operations.
19. **Implement a Queue Using Two Stacks** – Build queue functionality with stacks.
20. **Check Balanced Parentheses** – Validate matching brackets in expressions.
21. **Longest Palindromic Substring** – Identify the largest palindrome substring.
22. **Merge Overlapping Intervals** – Combine intervals that overlap.
23. **Top K Frequent Elements** – Find the k most frequent elements in an array.
24. **K-th Largest Element** – Determine the k-th largest number in an array.
25. **Set Matrix Zeroes** – Replace rows and columns with zeroes if any element is zero (constant space optimization).
